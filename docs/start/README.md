# Get started

These pages are for you if taskmill is new to you. They help you decide if it
fits, then take you to your first finished task.

| Page | Read this when… |
|---|---|
| [Why taskmill](why-taskmill.md) | you want to know if taskmill fits your project, and what it does not do |
| [Quickstart](quickstart.md) | you want to run your first task and see it in the dashboard, in about 15 minutes |

Ready to write code? The [tutorial](../tutorial/README.md) builds the
quickstart's shop step by step, in a project of your own. To see more
features at work, run the [shop example](../../examples/shop/README.md): one
small program that uses most of them, with a guided tour of its dashboard.
